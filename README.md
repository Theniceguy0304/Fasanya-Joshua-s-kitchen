# Fasanya Joshua's Kitchen

A responsive 4-page restaurant website built with HTML, CSS and JavaScript for the New Horizon Web Development Project.

**Author:** Fasanya Joshua
**Live site:** _add your Netlify/Render URL here_

## Pages
- `index.html` - Home (welcome, introduction, features)
- `about.html` - About (what we do, history, mission, vision, values)
- `services.html` - Menu & Services (6 dishes, filter buttons, 3 services)
- `contact.html` - Contact details and validated form

## Technologies
- **HTML5** - semantic elements (header, nav, main, section, article, address, footer), lists, forms, images
- **CSS3** - external stylesheet, variables, box model, positioning (sticky header)
- **Flexbox** - header/navigation, hero, features, services, footer
- **CSS Grid** - dish cards (3 columns, gap), about cards, two-column layouts
- **Media queries** - breakpoints at 900px (tablet) and 640px (mobile)
- **JavaScript** - mobile menu toggle, menu category filter, contact form validation with user feedback

## Notes
The contact form validates input but does not send messages, because no backend is connected.
Contact details are sample details.
